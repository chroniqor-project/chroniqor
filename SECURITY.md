# Security Policy

Chroniqor is experimental software. Version 0.1 is not intended for
real-money trading or production financial operations.

## Reporting a vulnerability

Do not report security vulnerabilities through public issues, pull requests
or discussions.

Use GitHub's private vulnerability reporting feature:

1. Open the repository's **Security** tab.
2. Select **Advisories**.
3. Select **Report a vulnerability**.
4. Include the affected version or commit, reproduction steps and potential
   impact.

Reports should include, when available:

- A clear description of the vulnerability.
- The affected version or commit.
- Reproduction steps.
- Potential impact.
- Suggested mitigation.
- Supporting logs or a proof of concept that does not expose secrets.

Do not include:

- API keys.
- Broker credentials.
- Database passwords.
- Private market data.
- Personal financial information.
- Credentials belonging to another person or organization.

## Response process

The Project Lead and authorized maintainers may review and classify the
report, request additional information, prepare a fix or mitigation privately
and coordinate disclosure when appropriate.

Chroniqor is an experimental project. No specific response or remediation
time is guaranteed.

Do not publicly disclose the vulnerability before the project has had a
reasonable opportunity to evaluate and address it.
