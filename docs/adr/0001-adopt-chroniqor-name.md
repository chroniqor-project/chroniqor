# ADR 0001: Adopt Chroniqor as the project name

## Status

Accepted.

## Date

2026-07-31

## Context

The original working name, SpringFXCore, coupled the project identity to the
Spring ecosystem and could create confusion with Spring projects or trademarks.
The project is intended to be a broader trading engine whose core remains
independent from Spring Boot.

## Decision

The project name is **Chroniqor**. The GitHub organization and primary
repository use `chroniqor`.

Spring Boot remains an implementation technology for the runtime, not part of
the project name or the definition of the core engine.

## Project identity

The Chroniqor name, official repositories, domains and visual identity are
managed separately from the Apache License 2.0 applied to the source code.

The software license does not automatically grant contributors governance
authority or ownership of official project assets.

## Consequences

- New documentation, packages and public references should use Chroniqor.
- Historical planning documents may still contain the former working name.
- The project should continue to review naming, trademark and package
  availability before a public release.

## Review triggers

This decision should be reviewed before:

- Formal trademark registration.
- Version 1.0.
- Formation of a legal entity.
- Transfer of significant project assets.
- Major commercialization.
